2. 작업범위
위 아키텍처를 기반으로 아래 작업범위 내에서 과제를 만들 수 있습니다. 아래 12개의 작업 범위가 모두 들어가야 하진 않습니다.  
12개 항목 중 원하는 만큼 선택하여 출제를 진행합니다. 문제지 작성시 사용해야 하는 AWS 서비스 및 SW stack을 모두 나열해주세요.  
과제를 위한 앱은 출제기관에서 별도로 생성할 수 없습니다. 배포되는 바이너리 파일들만 사용해야 합니다.  
인프라 스케일링에 관한 문제는 1과제에는 출제하지 않습니다. AWS 및 CNCF 툴을 활용한 클라우드 인프라 구축이 주요 문제가 되어야 합니다.  
편법으로 풀어질만한 문제들도 출제하면 안됩니다. 문제에서 사용하는 AWS 서비스는 ap-northeast-2 에서 사용 가능한 서비스여야 합니다.
채점 시 대기가 필요한 문항이 존재한다면 최대 몇 분 까지 대기 가능한지 문제지와 채점지에 명시합니다. 
제한 시간은 직종설명서를 참고합니다. 또한 채점스크립트 파일을 작성해서 제출해야 하며 리소스의 수정/삭제를 포함하는 채점은 진행할 수
없습니다. 채점스크립트는 여러 번 실행 하여도 동일한 결과를 출력 하도록 구성해야 합니다. 출제가 완료되면 반드시 직종설명서에 있는 출제 체크리스트를 확인해 문제와 채점지 장수, 제한 시간 등이 기준에 맞는지 확인합니다.
1. VPC (필수)
한개의 VPC 에 목적에 따라 여러개의 서브넷을 구성하는 문제를 출제합니다.
2. Container (필수)
Book 어플리케이션은 ECS 혹은 EKS 에서 구동될 수 있습니다. 컴퓨팅은 EC2,
Fargate 를 선택할 수 있습니다. 큰 비용이 나오지 않도록 사이즈를 명시합니다.
3. Database (필수)
Book 어플리케이션은 DynamoDB 를 사용합니다. DynamoDB 를 활용한 여러 문제를
출제할 수 있습니다.
4. Static page hosting (필수)
제공된 index.html, main.png 를 S3를 활용해 호스팅 하도록 합니다. CloudFront 를
통해 사용자가 웹페이지에 접근 할 수 있습니다.
5. Encryption Key (옵션)
사용하는 여러 서비스에 KMS를 연계할 수 있습니다. 다만 과금이 많이 되는
CloudHSM과 같은건 사용할 수 없습니다.
6. Container Registry (필수)
어플리케이션의 이미지를 저장하기 위해 ECR을 활용합니다. 채점 시 사용하는
이미지를 문제지에 명확히 기재합니다.
version: 1.0.0 (Last updated 2026-03-29)
7. WAF (옵션)
AWS WAF를 이용해 방화벽을 구성하는 문제를 출제 할 수 있습니다. 채점 시 선수가
구성하지 않은 부분으로 채점에 불이익을 받지 않도록 채점 방법을 명확히 명시합니다.
예를 들어 채점 시작 전 존재하는 기록으로 차단된 상태에서 채점을 시작해 불이익
당하는 일이 없도록 명확히 기존 기록을 클리어 하고 시작하는 등 의 내용을
추가합니다.
8. 로드밸런서 (필수)
어플리케이션은 ALB 나 NLB 를 통해서 접근 하도록 구성할 수 있습니다. 다만
유저는 CloudFront 로만 호출 할 수 있고 이후 로드밸런서로 호출 되어야 합니다.
9. Security (옵션)
IAM을 활용하여 문제를 출제할 수 있습니다. Policy 작성, Pod Identity, Assume role,
OIDC 구성 등 출제 할 수 있습니다.
10. Lambda (옵션)
Book어플리케이션으로 DynamoDB 에 저장한 데이터를 조회할 수 있는 GET 호출
API를 Python 으로 개발합니다. 출제 시 구체적인 입력과 출력 형식이 제공 되어야
하며, 과제 진행 중 저장한 데이터로 채점에 문제가 없도록 합니다.
11. Observability (옵션)
CloudWatch나 설치형 Prometheus, Grafana, Fluentbit을 이용한 문제를 출제 할 수
있습니다. 대쉬보드 구성, 메트릭 및 로그 수집과 같은 문제들 출제가 가능합니다.

12. Application(필수)
Book 애플리케이션은 콘서트 예약 정보를 받아 데이터베이스에 저장하는 POST API를
제공합니다. Book 어플리케이션은 구동을 위해서 AWS_REGION 과 TABLE_NAME
이라는 환경 변수를 필요로 합니다. 정상 구동 시 8080 포트가 바인딩 되며 /health
호출 시 200 OK 를 반환합니다.

- username: 구매자 이름 (String)
