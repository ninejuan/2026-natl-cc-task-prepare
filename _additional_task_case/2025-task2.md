5) Serverless Inventory
개요
Skills Inc.는 서버리스로 자사의 재고를 관리하는 시스템을 구축하길 원합니다. Step Functions, API Gateway, DynamoDB 등을 사용해 별도의 컴퓨팅 서비스를 사용하지 않고 다음의 요구사항을 만족할 수 있는 시스템을 구축해야 합니다. Lambda를 포함한 EC2, ECS 등의 컴퓨팅 서비스의 사용이 불가합니다. 리전은 us-west-1에서 작업합니다.

과제 설명
1. DynamoDB
- Table name: inventory
- 아래 예제와 같은 record를 사전에 생성합니다.
  - {“name”: “balance”, “value”: 1000}
  - {“name”: “stock”, “value”: 100}
- Scheme -
|KeyName|Type|Description|
|name|String|PK|
|value|Number||


2. Step Functions
State machine name: inventory-state-machine
State machine JSON input
  - sales: 판매량, 1 ~ 30 사이의 자연수로 입력
  - ex) {"sales": 15}
- State machine의 동작 구현  

3. API Gateway
DynamoDB의 inventory 테이블 내용을 조회하기 위해 /inventory API를 제공해야 합니다.
  - API Type: REST API
  - API name: inventory-rest-api
  - Stage name: v1
  - /inventory API는 GET 요청만 지원하며 integration type은 AWS Service Proxy로 지정해야 합니다.
  - 만약 /inventory의 query string(item)으로 mysecret으로 시작하는 문자열을 받을 경우 HTTP status code가 403이고 body가 “403 Forbidden”인 응답을 반환하도록 합니다.
  - 요청 예시 (응답은 큰 따옴표를 출력하지 않아야 함)
|Request|response|description|
|GET /inventory?item=balance|1000||
|GET /inventory?item=stock|100||
|GET /inventory?item=mysecret123|403 Forbidden|HTTP status code 403|
  - 채점 시 다음과 같은 URL로 HTTP 요청을 수행합니다. 또한 선수의 데스크탑이나 EC2 등 어디서든 접근 가능해야 합니다.
    https://5yb12xiewd.execute-api.us-west-1.amazonaws.com/v1/inventory?item=balance
